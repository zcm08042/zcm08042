### 一些习惯

- 能本地就不联网，能原生控件就不堆依赖
- 界面干净、可扫读，少即是多
- 单文件能解决的事，不拆成十个模块
- 数据属于使用者：可导出、可备份、可带走

### 技术

原生 HTML / CSS / JavaScript · Electron · Capacitor · MQTT · Python（tkinter / OpenCV）· CIMPro 高级事件与 UI 扩展
